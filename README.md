# CEASE Project Page

Continual Concept Erasure in Diffusion Models by Suppressing Cross Edit Interference

Authors: Yongliang Wu, Haori Lu, Jinqi Luo, Wei Cao, Xingyu Zhu, Yaoyao Liu.

CEASE suppresses interference between successive concept erasures in diffusion models. Evaluations cover 100 sequential edits of celebrities, artistic styles, and instances on Stable Diffusion v1.4, v1.5, and v2.1, showing a consistent balance between erasure and preservation.
